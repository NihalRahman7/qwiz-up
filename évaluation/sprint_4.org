* Sprint 4

** À faire dans ce sprint

*** Ce sprint a pour objectif l'établissement des requêtes HTTP vers un API externe. Ceci implique :

- La mise en place d'un serveur (réel ou fictif avec Postman ou autre)
- La création d'une source de données HTTP **réelle**
- Injection des sources de données dans les Modèles grâce à l'utilisation d'interfaces
- Le stoquage des données locales dans une BD sqlite, fichier, autre **via une source de données spécifique**

*** Souvenez-vous : 

- Les fils d'exécutions doivent être gérés dans les Présentateurs
- Les sources de données doivent fournir des entités du domaines
- Aucune notion de JSON, BD ou autre méthode de stoquage spécifique ne doit sortir de la source de données, même pas les exceptions spécifiques.

** Présentation

Vous devrez présenter, en équipe complète, votre application «fonctionnelle». Les écrans doivent être fonctionnels, les données peuvent être simulés par un API factice **mais pas codés en dur dans l'app elle-même**.

Vous n'avez pas à présenter le code, mais il devra être accessible sur Gitlab

- Durée : max 10 min.
- Date : 2/4 décembre
